# RAR Store — E-commerce Demo

A responsive, beginner-friendly storefront made with plain HTML, CSS and JavaScript.

## Features
- Responsive product grid
- Search and category filters
- Add-to-cart and quantity controls
- Cart total in Bangladeshi taka (৳)
- Demo checkout form (does not send orders or collect payments)
- No build tools or dependencies required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For local hosting, use VS Code Live Server or run `python -m http.server 8000` in this folder, then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository and upload all project files.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.

## Important
This is a front-end demo. Product data is sample data. Login, database, order management and real payment processing are not included. Never put private API keys or payment secrets in front-end files.
